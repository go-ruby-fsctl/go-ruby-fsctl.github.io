go-ruby-fsctl is the pure-Go, Ruby-runtime-independent core of the Ruby fsctl gem: a reflective adapter over the go-fsctl family of pure-Go Linux kernel-ioctl wrappers — loop, dm, btrfs and zfs. A Session exposes each subpackage's operations through typed methods returning Ruby-shaped values, plus a single dynamic Call entry point an rbgo binding drives from method_missing. Nothing here depends on the Ruby runtime, so it is equally usable as a standalone Go library.

A Ruby-shaped Session

One dynamic Call entry point over every go-fsctl subpackage:

s := fsctl.NewSession()
dev, _  := s.Call(ctx, "loop_attach", "/tmp/disk.img")   // "/dev/loop3"
subs, _ := s.Call(ctx, "btrfs_subvolume_list", "/mnt")   // Array of Hashes
_, _    = s.Call(ctx, "zfs_snapshot", "tank", "tank/fs@backup")
The rbgo require "fsctl" binding that wires this adapter into the Ruby interpreter lives in go-embedded-ruby, not in this org.
